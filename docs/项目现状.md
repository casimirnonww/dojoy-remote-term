## 暂缓的想法

### 网页上点按钮添加设备
曾经决定做，排在 Windows 接入之后，还没开始。现在加设备的流程是：改 `hosts.json`，运行 `deploy/render_config.py --write-web web/hosts.js`，提交，然后在 VPS 上再运行一次安装命令。

### 除 GitHub 外的自建登录（方案未确认）
讨论到的方向是：GitHub 和自建账号都能登录，任选其一。

自建账号用「认电脑 + 手机验证码」：
- 新电脑第一次登录：用户名、密码，加手机验证器 App 的 6 位码（TOTP），然后记住这台电脑 90 天。
- 之后在这台电脑上只要输验证码。

当时的设计要点：
- 用 Python 标准库写一个小服务（风格同 `status/receiver.py`），只监听 `127.0.0.1:4190`。
- nginx 的 `auth_request` 先问 oauth2-proxy；返回 401 时，用 `proxy_intercept_errors` 和 `error_page 401 = @auth_local` 再问自建服务。两者任一通过即可。
- 没登录时跳到 `/login/` 选择页，页面上也有「用 GitHub 登录」。
- 密码用 `hashlib.scrypt`；验证码是 RFC 6238 的 TOTP，前后各容忍一步，同一个码不能用第二次。
- 会话 cookie 12 小时，用 HMAC 签名，里面带「账号版本号」。重置密码或删除账号时版本号加一，旧会话随之作废。
- 「认电脑」cookie 是随机值，服务端只存它的哈希，`Path=/login/`。
- 入口机在 SNI 分流后面，看不到访问者 IP，所以按账号锁定：连续错 5 次就锁，时间逐步加长。即使自建账号被锁，GitHub 登录照常可用。
- 管理命令设想为 `remote-term-admin login-add / login-list / login-reset / login-forget / login-remove`：在终端里显示二维码（用 `qrencode`），并要求当场输入一次验证码确认。

不建议「只用验证码」登录：6 位码只有约百万分之一的猜中率，又不能按 IP 限制尝试次数，而登录后就能打开所有机器的终端。

## 怎么接着开发

- **分支**：在功能分支上开发，开 PR，CI 全绿后 squash 合并。合并后，入口机要再运行一次安装命令才会生效。
- **本地检查**：
  ```
  python3 -m unittest discover -s status
  python3 -m unittest discover -s deploy
  python3 deploy/render_config.py --check-web web/hosts.js
  shellcheck deploy/*.sh deploy/*/*.sh deploy/gateway/remote-ttyd-ssh
  node --check web/app.js
  ```
- **改前端**：用模拟的 `status.json` 起一个静态服务（`python3 -m http.server`），用 Playwright 按真实视口截图，检查运行概览区域是否需要滚动。
  - 无头 Chrome 的窗口最小只有 500px 宽，手机宽度要用 Playwright 的视口模拟。
  - 模拟数据的时间戳必须是当前时间：超过 90 秒算过期，晚于当前时间超过 10 秒会被判为异常。
- **CI 里的 `deploy/tests/gateway_probe.py`**：会用 Mac 自带的 python3 访问真实的入口机，只发一个编造的 token，预期返回 401。这一步只作参考，失败也不影响 CI 结果。
- **入口机上的常用命令**（都要 `sudo`）：
  | 命令 | 作用 |
  |---|---|
  | `remote-term-admin list` | 每台机器的接入进度 |
  | `remote-term-admin join <id> --force` | 有意重新接入某台；会换 token |
  | `remote-term-admin token <id>` / `revoke-token <id>` | 轮换或作废某台的上报 token |
  | `remote-term-admin sync` | 处理接入登记；平时自动运行 |
- **不变量**：更新入口机（重新运行安装命令、`join-all`）永远不能换掉或吊销一台机器正在用的 token。只有上表里显式的 `join --force`、`token`、`revoke-token` 可以。`deploy/tests/test_deploy.py` 的 `JoinAllTests` 守着这一点。
